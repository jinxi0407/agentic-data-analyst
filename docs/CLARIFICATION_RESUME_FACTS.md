# QueryMate 当前可核验事实

版本限定：功能冻结 `269a441`，回归协议归档 `b41ca45`，发布引用为 `v1.2.0`。
本页只使用当前修复代码在已揭晓固定200题上的新回归结果，不是新盲测成绩。

在200条自建冻结混合测试中，覆盖140条明确问题与60条单歧义问题，
允许一次经审核的模拟用户补充后，结果集匹配准确率由71.00%（142/200）
提升至77.50%（155/200），提升6.50个百分点。

- 明确问题：OFF 125/140（89.29%），ON 123/140（87.86%），净回退2题。
- 歧义问题：OFF 17/60（28.33%），ON 32/60（53.33%），提升25.00pp。
- ON 只能在实际反问后获得一次预先冻结并经过字段审核的模拟回答。
- 这是自建合成混合测试，不是外部独立盲测，也不代表真实线上用户分布。
- 两种模式共享生产 SQL 引擎、模型、业务上下文、数据库与评分逻辑；
  ON 获得额外用户信息，因此结果体现交互效果，不是等信息模型能力。
- Precision 32/32（100.00%），Recall 32/60（53.33%），F1 64/92（69.57%，公式计数）。
- 全部歧义题严格交互成功22/60（36.67%），全体严格成功145/200（72.50%）；漏澄清28/60（46.67%）。
- 平均耗时 OFF 4.153s / ON 5.660s；平均模型调用1.075 / 2.225次，不含用户思考时间。
- 明确问题回退、漏澄清及结构校验失败均保留，不宣称对所有问题都有提升。

简历表述可使用首段，不写“显著提升”“稳定提升”或“可靠解决全部业务歧义”。
