# QueryMate 当前可核验事实

版本限定：以下数字属于原冻结 Gate（行为冻结 `8fb1e3a`，数据冻结 `597d5f2`，
结果归档 `0bb12e4`），不代表之后的澄清交互修复版本。本轮不新增简历成绩。

在200条自建冻结混合测试中，覆盖140条明确问题与60条单歧义问题，
允许一次模拟用户补充后，结果集匹配准确率由69.0%提升至73.5%，
提升4.5个百分点；明确问题子集准确率为89.3%。

- OFF 138/200；ON 147/200；明确问题 ON 125/140。
- ON 只能在实际反问后获得一次预先冻结并经过字段审核的模拟回答。
- 这是自建合成混合测试，不是外部独立盲测，也不代表真实线上用户分布。
- 两种模式共享生产 SQL 引擎、模型、业务上下文、数据库与评分逻辑；
  ON 获得额外用户信息，因此结果体现交互效果，不是等信息模型能力。
- 89.3% 只属于明确问题子集，不是全体准确率；不能将历史 F1 或直接查询耗时混入本轮。
- 全部歧义题严格交互成功12/60，漏澄清31/60，指标歧义子集出现退化；完整限制不隐藏。

简历表述可使用首段，不写“显著提升”“稳定提升”或“可靠解决全部业务歧义”。
